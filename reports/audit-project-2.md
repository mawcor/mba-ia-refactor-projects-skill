  ## Findings                                                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                                 
  ### [CRITICAL] Hardcoded Credentials / Secrets                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                 
  File: src/utils.js:2-4                                                                                                                                                                                                                                                                                         
  Description: As chaves dbPass e paymentGatewayKey estão definidas inline no objeto de configuração.                                                                                                                                                                                                            
  Impact: Falha grave de segurança, vazamento de credenciais.                                                                                                                                                                                                                                                    
  Recommendation: Extrair para variáveis de ambiente usando ferramentas como dotenv.                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                 
  ### [CRITICAL] God Class / God File / God Method                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                 
  File: src/AppManager.js:4-140                                                                                                                                                                                                                                                                                  
  Description: A classe AppManager concentra múltiplas responsabilidades: instanciação do banco de dados, definição do schema, definição de rotas de API, regras de negócio para checkout e processamento de pagamentos.                                                                                         
  Impact: Impossível de testar isoladamente, violando o SRP (Single Responsibility Principle) e dificultando a manutenção.                                                                                                                                                                                       
  Recommendation: Dividir o código separando responsabilidades em Rotas, Controllers e Models.                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                                                 
  ### [HIGH] Queries N+1 (N+1 Problem) / Callback Hell no DB                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                                 
  File: src/AppManager.js:89-125                                                                                                                                                                                                                                                                                 
  Description: O endpoint /api/admin/financial-report realiza loops .forEach dentro de queries do banco de dados (callback hell) e dispara múltiplas consultas N+1 para matrículas, pagamentos e usuários associados.                                                                                            
  Impact: Queda drástica de performance conforme o número de dados cresce, além da complexidade imensa do aninhamento de callbacks.                                                                                                                                                                              
  Recommendation: Substituir as buscas individuais por um JOIN ou separar de forma otimizada via Promises / async-await.                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                 
  ### [MEDIUM] Ausência de Tratamento Centralizado de Erros (Error Handling)                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                                 
  File: src/AppManager.js:41-70                                                                                                                                                                                                                                                                                  
  Description: Tratamento de erros repetitivo (if (err) return res.status(500).send(...)) está espalhado diretamente dentro das lógicas de endpoints HTTP.                                                                                                                                                       
  Impact: Inconsistência nas respostas de erro para o cliente e código duplicado.                                                                                                                                                                                                                                
  Recommendation: Criar um middleware global de tratamento de erros no Express para padronização.                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                 
  ### [MEDIUM] Lógica de Acesso a Dados Espalhada (No Repository/Model pattern)                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                 
  File: src/AppManager.js:37-76                                                                                                                                                                                                                                                                                  
  Description: Diversas queries SQL (utilizando this.db.get, this.db.run) acopladas diretamente na lógica de negócio das rotas.                                                                                                                                                                                  
  Impact: Impossível fazer a substituição fácil do ORM ou do banco de dados, além de dificultar o mocking.                                                                                                                                                                                                       
  Recommendation: Criar um padrão Model ou Repository (ex. UserModel, CourseModel) que seja responsável apenas pela persistência.                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                 
  ### [LOW] Retornos de API Inconsistentes / Magic Numbers                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                                 
  File: src/AppManager.js:48-60                                                                                                                                                                                                                                                                                  
  Description: Os retornos do sistema misturam envio de strings puras (ex: res.send("Bad Request"), res.send("Erro DB")) e objetos JSON formatados (ex: res.json({ msg: "Sucesso"... })).                                                                                                                        
  Impact: Difícil para clientes da API consumirem os dados de forma previsível (uma hora é text/html, outra application/json).                                                                                                                                                                                   
  Recommendation: Padronizar o corpo de resposta de sucesso e erro para JSON uniformemente.                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                 
  ### [LOW] Código Acoplado sem Injeção de Dependências                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                 
  File: src/AppManager.js:7                                                                                                                                                                                                                                                                                      
  Description: A instância do banco new sqlite3.Database(':memory:') é invocada e criada diretamente dentro do construtor de AppManager.                                                                                                                                                                         
  Impact: Dificulta injetar outros tipos de bancos de dados ou instâncias de simulação (mock) em testes unitários.                                                                                                                                                                                               
  Recommendation: Passar a instância do banco de dados pelo construtor (Injeção de dependência).
